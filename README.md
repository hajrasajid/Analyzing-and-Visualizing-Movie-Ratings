# IMDb Top 1000 Movies Analysis

This project performs Exploratory Data Analysis (EDA) on the IMDb Top 1000 Movies dataset using Python. The goal is to extract meaningful insights from movie data and visualize key trends in ratings, genres, and filmmakers.

## Project Workflow
  - Loaded dataset using Google Colab
  - Handled missing values and removed duplicate records
  - Performed data exploration and statistical analysis
  - Visualized distributions of IMDb ratings using histograms and boxplots
  - Identified top-rated movies based on IMDb ratings
  - Analyzed genre popularity and average ratings
  - Explored top directors and actors based on frequency
## Key Insights
  - Distribution of IMDb ratings across top movies
  - Highest rated movies in the dataset
  - Most common and top-performing genres
  - Most frequent directors and lead actors

This project helps understand how movie ratings, genres, and cast influence popularity and provides a strong foundation for data analysis and visualization skills.
